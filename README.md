# Государственный архив города Москвы — учебный Django-проект

Готовый учебный сайт на Django с административным управлением контентом.

## Возможности

- Главная страница с публикациями и поиском по заголовку, описанию и текстовым блокам.
- Статьи создаются администратором через Django Admin.
- Содержимое статьи состоит из упорядоченных текстовых и графических блоков, поэтому изображение можно расположить между частями текста.
- Если публикаций нет, отображается «Информация отсутствует».
- Регистрация, авторизация и выход.
- Комментарии доступны только зарегистрированным пользователям.
- Комментарии можно скрывать через админку.
- «Об организации» и «Контакты» заполняются через админку.
- Форма обратной связи сохраняет обращения в отдельном разделе админки.
- Отдельная карта сайта.
- Оформленная страница 404.
- Режим «Для слабовидящих»: повышенный контраст, увеличенный текст, видимый focus, отключение анимаций, сохранение режима в localStorage.
- Адаптивный интерфейс.

## Требования

- Python 3.10+.
- Django 5.2.17.
- Pillow для загрузки изображений.

## Запуск в Windows

```powershell
cd moscow_archive
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте:

- сайт: http://127.0.0.1:8000/
- админка: http://127.0.0.1:8000/admin/

## Что заполнить после первого запуска

1. В админке создайте объект «Страница “Об организации”».
2. Создайте объект «Контактная информация».
3. Создайте статью и добавьте внутри нее блоки. Для текста выберите тип «Текст», для изображения — «Изображение». Поле «Порядок» определяет последовательность блоков.
4. Отметка «Опубликовано» управляет отображением статьи на сайте.
5. Обращения из формы находятся в разделе «Обращения».

## Права

Создание, изменение и удаление статей и информационных страниц ограничено суперпользователем. Обычные зарегистрированные пользователи не получают доступа к административной панели и могут только использовать пользовательский функционал сайта, включая комментарии.

## Важно для развертывания

Проект настроен для локальной учебной демонстрации и использует SQLite. Перед публикацией в интернете замените `SECRET_KEY`, установите `DEBUG = False`, настройте `ALLOWED_HOSTS`, HTTPS, production-хранилище статических/media-файлов и при необходимости PostgreSQL.

Фраза о соответствии ГОСТ Р 52872-2012 в задании реализована через отдельный режим повышенной доступности и основные веб-практики доступности. Для формального подтверждения полного нормативного соответствия требуется отдельная проверка всех требований стандарта и итогового контента сайта.
