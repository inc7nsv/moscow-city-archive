# Moscow City Archive

Веб-приложение **«Государственный архив города Москвы»**, разработанное на Django в рамках учебной практики.

Система предназначена для публикации архивных и информационных материалов, предоставления пользователям сведений о деятельности городского архива и организации взаимодействия с посетителями сайта.

## Основные возможности

* публикация и редактирование статей через Django Admin;
* добавление изображений и текстовых блоков в статьи;
* поиск по опубликованным материалам;
* просмотр отдельных страниц статей;
* регистрация и авторизация пользователей;
* добавление комментариев авторизованными пользователями;
* управление комментариями через административную панель;
* страница «Об организации»;
* страница «Контакты»;
* форма обратной связи с сохранением обращений в административной панели;
* карта сайта;
* пользовательская страница ошибки 404;
* адаптивный интерфейс для мобильных устройств;
* специальный режим отображения «Для слабовидящих».

## Установка и запуск

Клонировать репозиторий:

```bash
git clone https://github.com/USERNAME/moscow-city-archive.git
cd moscow-city-archive
```

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать его в Windows:

```bash
venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Выполнить миграции базы данных:

```bash
python manage.py migrate
```

Создать учетную запись администратора:

```bash
python manage.py createsuperuser
```

Запустить сервер:

```bash
python manage.py runserver
```

После запуска сайт будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

Административная панель:

```text
http://127.0.0.1:8000/admin/
```

## Административная панель

Через Django Admin администратор может создавать и редактировать статьи, добавлять текстовые и графические материалы, управлять комментариями пользователей, изменять информацию об организации и контактные данные, а также просматривать обращения, отправленные через форму обратной связи.

## Пользователи

Неавторизованные посетители могут просматривать опубликованные материалы, выполнять поиск по сайту и использовать форму обратной связи.

Зарегистрированные пользователи дополнительно получают возможность оставлять комментарии к статьям.

Администратор осуществляет управление содержимым сайта через стандартную административную панель Django.

## Доступность

На страницах сайта предусмотрен режим **«Для слабовидящих»**, предназначенный для повышения доступности веб-интерфейса. Реализованы увеличение размера текста, контрастное отображение элементов интерфейса, визуальное выделение элементов при клавиатурной навигации и другие средства доступности.

При разработке интерфейса учитываются требования доступности веб-ресурсов, установленные российскими стандартами.
