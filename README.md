# Moscow City Archive

Веб-приложение **«Государственный архив города Москвы»**, разработанное на Django в рамках учебной практики.

Система предназначена для публикации архивных и информационных материалов, предоставления пользователям сведений о деятельности городского архива и организации взаимодействия с посетителями сайта.

## Основные возможности

* публикация и редактирование статей через Django Admin;
* добавление изображений и текстовых блоков в статьи;
* поиск по опубликованным материалам;
* просмотр отдельных страниц статей;
* регистрация и авторизация пользователей;
* добавление комментариев авторизованными пользователями;
* управление комментариями через административную панель;
* страница «Об организации»;
* страница «Контакты»;
* форма обратной связи с сохранением обращений в административной панели;
* карта сайта;
* пользовательская страница ошибки 404;
* адаптивный интерфейс для мобильных устройств;
* специальный режим отображения «Для слабовидящих».

## Технологии

Проект разработан с использованием:

* Python;
* Django;
* SQLite;
* HTML5;
* CSS3;
* JavaScript;
* Django Templates.
